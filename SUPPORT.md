# Support

## Usage and setup questions

Use [GitHub Discussions](https://github.com/ZenulAbidin/electrum-silent-payments-sender/discussions)
for installation, testnet usage, compatibility, and other questions. Include
your operating system, Electrum version, plugin version, network, and wallet
type.

## Bug reports

Use the repository's structured
[bug report form](https://github.com/ZenulAbidin/electrum-silent-payments-sender/issues/new/choose)
for reproducible, non-security defects. Search existing issues first and reduce
the report to synthetic or testnet data.

## Security reports

Do not discuss suspected vulnerabilities publicly. Follow
[SECURITY.md](SECURITY.md) and use
[private vulnerability reporting](https://github.com/ZenulAbidin/electrum-silent-payments-sender/security/advisories/new).

## Safety and privacy

Never post or send wallet seeds, private keys, receiver JSON files, passwords,
wallet files, or other secrets. Maintainers and contributors will never need
those values to diagnose a report.

This independent, unaudited project is provided without warranty. Community
support is best effort and cannot provide emergency transaction recovery,
financial advice, or a guarantee that funds can be recovered. Test on testnet
and use a small amount for any first mainnet payment.
